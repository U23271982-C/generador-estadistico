# 📊 Generador Estadístico De Eventos Sísmicos Del Perú 1960-2021

Proyecto en **Java** para generar y analizar datos estadísticos.

Este repositorio contiene una herramienta que permite crear muestras de datos numéricos automáticamente, calcular medidas estadísticas básicas y presentar resultados descriptivos relevantes.

*(Se utilizó los datos de)*  ["Datos Libres del Perú"]([https://es.wikipedia.org/wiki/N%C3%BAmero_pseudoaleatorio?utm_source=chatgpt.com](https://www.datosabiertos.gob.pe))

---

## 📌 Descripción

**Generador Estadístico** es una aplicación en Java que simula conjuntos de datos numéricos y realiza análisis estadístico básico sobre estos, incluyendo medidas centrales, dispersión y distribución.

Este tipo de herramienta es útil para:

- Práctica de estadística computacional  
- Simulación de muestras para experiencias educativas  
- Validación de algoritmos estadísticos

---

## 🚀 Características

- ✅ Generación de datos numéricos pseudoaleatorios  
- ✅ Cálculo de medidas estadísticas básicas: media, mediana, moda  
- ✅ Medidas de dispersión: rango, varianza, desviación estándar  
- ✅ Representación simple de frecuencias o histogramas  
- ✅ Interfaz de entrada por consola (o GUI si implementada)  
- ✅ Código modular y educativo
